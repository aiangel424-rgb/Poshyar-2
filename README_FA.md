# پوش‌یار AI — راهنمای راه‌اندازی و شماره‌گذاری

## شماره‌ها
**[۱] آدرس پایه سرویس:** بعد از ساخت و Deploy کردن Space از صفحهٔ سرویس کپی می‌شود؛ قالب نمونه: `https://YOUR-USER-poshyar-segment.hf.space` (این آدرس نمونه است، نه آدرس فعال).

**[۲] آدرس endpoint تشخیص:** آدرس پایه + `/segment`؛ نمونه: `https://YOUR-USER-poshyar-segment.hf.space/segment`. این را در کادر «[۲] آدرس سرویس تشخیص ماسک» وب‌اپ وارد کنید.

**[۳] توکن سرویس:** در این نسخه خالی بگذارید. این API نمونه احراز هویت ندارد؛ برای عکس‌های حساس یا استفاده عمومی باید proxy خصوصی و احراز هویت اضافه شود. توکن محرمانه را در HTML عمومی نگذارید.

**[۴] خروجی ماسک:** PNG سیاه‌وسفید؛ سفید=لباس قابل‌ویرایش، سیاه=پوست/صورت/مو/پس‌زمینه. نتیجهٔ مدل ممکن است نیاز به اصلاح دستی داشته باشد.

**[۵] آدرس endpoint تعویض لباس:** در این نسخه هنوز راه‌اندازی نشده است.

**[۶] کلید API تعویض لباس:** فعلاً وارد نکنید؛ کلیدها نباید در کد سمت مرورگر ذخیره شوند.

## راه‌اندازی سرویس تشخیص
1. وارد https://huggingface.co/spaces شوید و وارد حساب خود شوید.
2. Create new Space را بزنید و نامی مثل `poshyar-segment` انتخاب کنید.
3. SDK را روی `Docker` قرار دهید.
4. فایل‌های `app.py`, `requirements.txt`, `Dockerfile`, `README.md` را از این بسته در ریشهٔ Space بارگذاری کنید.
5. منتظر Build و شروع سرویس بمانید. بار اول ممکن است مدل زمان ببرد تا دانلود شود.
6. آدرس پایهٔ Space را باز کنید؛ باید JSON وضعیت سرویس نمایش داده شود. برای بررسی سلامت، `/health` را به انتهای آدرس اضافه کنید.
7. آدرس `[۲]` را در وب‌اپ وارد کنید؛ `[۳]` را خالی بگذارید.
8. عکس آزمایشی انتخاب کنید و «تشخیص خودکار لباس» را بزنید.

## محدودیت‌ها و حریم خصوصی
- این سرویس رایگانِ نامحدود یا همیشگی تضمین‌شده نیست؛ هاست رایگان ممکن است کند شود یا به خواب برود.
- تصویر برای پردازش به سرور میزبانی ارسال می‌شود. تا وقتی سرویس و سیاست حریم خصوصی آن را بررسی نکرده‌اید، عکس محرمانه نفرستید.
- این API فقط ماسک می‌سازد؛ تولید لباس جدید نیازمند مدل ویرایش تصویر جداگانه است.
- مدل انتخابی پیشنهادی `fashn-ai/fashn-human-parser` است. پیش از استفاده، مجوز و شرایط مدل را در https://github.com/fashn-AI/fashn-human-parser بررسی کنید.
- این نمونه برای تولید عمومی نهایی نیست؛ به احراز هویت، محدودسازی نرخ، CORS محدود و آزمون مدل نیاز دارد.
